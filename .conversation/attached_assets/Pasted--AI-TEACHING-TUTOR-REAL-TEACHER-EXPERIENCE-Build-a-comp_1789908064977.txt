# AI TEACHING TUTOR — REAL TEACHER EXPERIENCE

Build a complete AI Teaching Tutor web application that feels like a **real human teacher teaching a student in a classroom**, not like a normal AI chatbot.

The main goal is:

> A student enters ANY educational topic, and the AI teacher teaches that topic step-by-step using a digital/chalk-board style interface, just like a real teacher would explain it in a classroom.

The teacher should use simple English, write important points on the board, explain them verbally/textually, give real-life examples, ask questions, and check whether the student understood.

---

## 1. CORE IDEA

The application should simulate a real teacher.

For example, if the student enters:

"Photosynthesis"

The AI should NOT simply generate a large paragraph.

Instead, it should behave like a teacher:

### Teacher starts:

"Okay everyone, today we are going to learn Photosynthesis."

Then the teacher writes on the board:

PHOTOSYNTHESIS

Plants → Make their own food

Then explains:

"Plants need food just like we do. But plants cannot go to a shop and buy food. So, how do they get food?"

Pause and ask the student:

"Can you guess?"

Then continue:

"Plants make their own food using sunlight, water and carbon dioxide."

Then write on board:

Sunlight + Water + CO₂
↓
Glucose + Oxygen

Then explain each part clearly.

The application should create this kind of teaching experience for ANY topic.

---

# 2. TEACHING STYLE

The AI must behave like a patient, experienced human teacher.

Teaching style:

* Very simple English
* Clear explanations
* Short sentences
* Step-by-step teaching
* No unnecessary complicated terminology
* Explain difficult words immediately
* Use real-world examples
* Use analogies
* Ask questions during teaching
* Give small checkpoints
* Correct mistakes politely
* Repeat concepts when the student struggles
* Adjust difficulty according to the student
* Do not dump the entire topic at once

The AI should feel like:

"Teacher + Digital Board + Personal Tutor"

NOT:

"ChatGPT-style text conversation"

---

# 3. DIGITAL BOARD

The main teaching screen should contain a large interactive digital board.

The board can have two visual modes:

### Mode 1 — Chalkboard

Dark classroom-style board.

Teacher writes using white/chalk-like text.

### Mode 2 — Digital Whiteboard

Clean white digital board.

Teacher writes using dark text, diagrams, arrows, formulas and highlights.

Allow the student to switch between:

[ Chalk Board ] [ Digital Board ]

The board should support:

* Text
* Headings
* Underlining
* Highlighting
* Arrows
* Boxes
* Simple diagrams
* Formulas
* Tables
* Step numbers
* Flowcharts
* Mathematical equations
* Images where useful

The board should NOT look like a normal text editor.

It should visually feel like a teacher is writing on a classroom board.

---

# 4. TEACHER WRITING ANIMATION

Very important.

Do not show the complete board content instantly.

When the teacher explains something, the corresponding content should appear on the board gradually.

Example:

Teacher says:

"First, let's understand what a variable is."

Then the board writes:

VARIABLE

Then:

A variable stores a value.

Then:

age = 20

The writing should appear naturally, similar to a teacher writing on a board.

Use smooth handwriting/typewriter animation.

The student should feel:

"The teacher is teaching me right now."

# 8. STUDENT INTERACTION

The student should be able to interrupt the lesson.

Provide:

"Ask Teacher"

input box.

Example:

Student:

"I don't understand step 2."

Teacher:

"No problem. Let's go slowly."

Then explain step 2 again using an easier example.

The teacher should NEVER respond negatively.

Use phrases such as:

"No problem."

"Let's try another example."

"Think about it this way..."

"Good question."

"Let's go back one step."

---

# 9. UNDERSTANDING CHECKPOINTS

The AI teacher should periodically ask questions.

Example:

Teacher:

"Before we continue, let me check your understanding."

Question:

"What does a variable store?"

Options:

A. Only text
B. A value
C. Only numbers
D. Nothing

Student selects B.

Teacher:

"Correct! Good job."

If wrong:

"Not quite. Let's look at it again."

Then explain the concept.

Do not immediately reveal the answer without explanation.

# 13. TEACHING FLOW

Every lesson should follow a natural teaching flow.

### Step 1 — Introduction

Tell the student what they will learn.

### Step 2 — Why is this important?

Give a simple reason.

### Step 3 — Basic concept

Explain the foundation.

### Step 4 — Board explanation

Write important information on the board.

### Step 5 — Example

Give a simple real-world example.

### Step 6 — Step-by-step explanation

Break the concept into small parts.

### Step 7 — Visual explanation

Use diagrams, arrows, formulas or flowcharts where useful.

### Step 8 — Check understanding

Ask a short question.

### Step 9 — Practice

Give a small problem.

### Step 10 — Feedback

Evaluate the student's answer.

### Step 11 — Recap

Summarize the important points.

### Step 12 — Next step

Ask:

"Would you like to continue to the next concept?"

---

# 14. DO NOT OVERLOAD THE STUDENT

This is extremely important.

Do NOT display huge paragraphs.

Instead:

One concept
↓
Simple explanation
↓
Example
↓
Board writing
↓
Question
↓
Next concept

The student should feel that the teacher is teaching them personally.

---

# 15. SMART ADAPTIVE TEACHING

The AI should remember the student's current lesson progress.

If the student repeatedly gets questions wrong:

Reduce difficulty.

Give another example.

Use simpler language.

If the student answers correctly multiple times:

Gradually increase difficulty.

The teacher should adapt dynamically.

---

# 16. BOARD COMMAND SYSTEM

Create a structured response system between the AI and frontend.

The AI should return structured lesson information such as:

{
"teacher_text": "...",
"board_action": "write",
"board_content": "...",
"board_type": "formula",
"ask_question": false,
"step": 1
}

Possible board actions:

* clear
* write
* highlight
* underline
* draw_arrow
* draw_box
* formula
* diagram
* table
* flowchart

This allows the frontend to control exactly what appears on the board.

# 27. EXAMPLE COMPLETE LESSON

If student enters:

"Explain Binary Search"

The experience should be approximately:

Teacher:

"Today we are going to learn Binary Search."

Board writes:

BINARY SEARCH

Teacher:

"First, remember one important thing."

Board:

ARRAY MUST BE SORTED

Teacher:

"Binary Search works on sorted data."

Board:

[10, 20, 30, 40, 50, 60, 70]

Teacher:

"Imagine you are searching for 60."

Teacher highlights the middle:

40

Teacher:

"Is 60 smaller or larger than 40?"

Student:

"Larger."

Teacher:

"Exactly! So we don't need to search the left half."

Board visually removes the unnecessary half.

Then continue step-by-step.

This should feel like an actual teacher solving the problem on a board.
